## 执行顺序与交付

1. 母题筛选：列出300道候选，保存稳定题号、模块、难度、来源、已有题族、是否含图及可改动条件。分散知识点和来源，优先避开源解析错误和条件争议；已知近重复题族优先只选一个母题。母题仍属于1500道公开题，不另加到数量中。
2. 首批30道试做：每年级10道，模块按配额分配，难度目标12/12/6。优先用纯文字母题验证流程；修改数值、条件关系或情境，维持主要知识和推理任务，仅改人名或选项顺序不计有效变式。
3. 每个草稿保存四选项、候选答案、简短验算、修改说明及parent_id/family_id。检查定义域、分母不为零、根的有效性、选项互不等价且只有一个正确选项。适用题型采用程序辅助核算；不把结构通过或生成者自检当作可靠标准答案。
4. 试做通过后按批扩至300道。含图母题允许使用：如果变更了图上数字、位置或条件，必须同步生成对应图，保留母题图和变式图的区别；不能用原图搭配相互矛盾的新题干。不依赖修改图示的情境优先。
5. 整理1800题初版和300个题对；同一题族放到同一侧，暂定开发集150题、测试集1650题。随后再开发评测程序并用开发集试运行，质量复核和最终冻结仍按原计划后续阶段执行。

## 子智能体分工

变式明确标记source_type=variant，来源保留母题链接、生成者标识和生成时间；候选答案来自变式验算，不照搬源题答案，也不将生成题冒充公开原题。

| 工作 | 岗位/模型 | 责任 |
|---|---|---|
| 母题候选筛选、来源与题族字段、配额统计 | Luna | 执行固定规则，疑点回交主代理 |
| 数学变式生成、复杂条件与图文一致性 | 既定复杂生成岗位（Sol）＋主代理 | 生成有效修改，记录草稿答案和验算依据 |
| 格式、唯一题号、关联、重复与批次汇总 | Luna＋本地检查程序 | 不将源题或无效改写计为变式 |
| 风险题与答案分歧处理 | 主代理；需要时由生成者之外的复核代理处理 | 保留分歧与处置记录，不冒充全库已验算 |

现阶段不新增付费模型API调用或正式实验。完整解析仍可选，但每个变式必须有足以核对候选答案的简短验算依据。当前难度仍暂定，不要求教师或学生正确率、用时采集。
