# 网上困难题补采规则

2026-10-13按用户要求采用来源优先的补采方式，不安排教师复核或目标年级学生正确率、用时采集作为难度标注的前置条件。已有1500题的模型暂定标签保留其原始依据，不能改称网上来源标签。

优先检索现成的困难单选题、压轴选择题、带答案的培优专题和考试原卷；整套取得公开可访问材料后集中提取。顺序为：完整题面与四个选项 → 来源明确答案 → 年级/模块 → 来源难度证据 → 去重与格式检查 → 同年级/模块替换记录。完整解析可选，不额外要求用户补充。

每题分别保存以下证据：

| 类型 | 用途与限制 |
|---|---|
| 逐题困难标签/数值 | 保留原值、原尺度说明、网址与题号；有公开尺度说明才映射，数值不冒充本项目学生实测正确率 |
| 压轴专题定位 | 保留专题标题、所在题型与原题位置；可作来源筛选证据，不声称每题有独立难度系数 |
| 竞赛卷来源 | 只说明出处，不能自动等于困难或适合初中课程 |
| 模型任务判断 | 保存具体推理依据，与前三项分开；没有来源困难证据的题仍需明确称暂定 |

用户随后明确授权困难题补采缓慢时加入图像题；当前已启用文字＋图片。四选一、来源答案明确，且文字与所有必要题图一并完整的题计为可用图像候选。只取得题干却缺必要图片、公式或答案的题暂存。题库公开难度但答案需登录的只登记题源；文字预览丢公式的须用实际公开展示题页核对。

新增图片保存原图或仅裁取对应图形，不重绘、不猜条件；区分题干图与A/B/C/D选项图，逐图记录来源、文件路径及SHA-256。输入图片不能混入答案、解析或别题；原材料整页另作来源证据。通用导出包必须带图片，本地浏览页内置图片，可离线查看。输入规则见config/input_policy.json。

新增的困难题从同年级、同模块的过量基础/中等题中替换，1500总量与年级模块配额保持；不能为了300困难目标抬高旧题标签。来源标签也保留“来源认定/暂定”状态，不升级为实测难度或已完成全库数学验算。

2026-10-14本轮已完成主库替换：1500题、各年级500题及模块配额保持，暂定难度600基础/600中等/300困难。困难题含98道纯文字、202道含图；纯文字困难题覆盖数与式17、方程与不等式30、函数26、几何20、统计与概率5道。图形题只扩大候选范围，未设置必须带图的条件。

各年级困难题26、91、183道，年级内部难度分布仍不均衡。全库比例达到设计目标并不意味着每个年级的比例都已满足，也不意味着难度获得学生实测校准。旧首批4道图像题示例保留在data/public_image_draft/，不另行计入完成数。主库通用包和本地页面均包含本轮图片；完整结果见data/reports/completion_report.md。
