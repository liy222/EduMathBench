# 原阶段计划：本地评测程序与开发集试运行

1800题初版与暂定划分已于2026-10-14完成。按用户要求，当前采用split-policy-v0.2：dev为150公开、0变式，test为1350公开＋300变式；300个完整母题—变式对及整个关联题族均在test。debug100仅来自dev，只含100道公开题。当前数据入口为data/benchmark_draft/。

1. 实现本地数据加载器与输入检查。只读取*_inputs.jsonl，核查图片字段位置、相对路径和摘要；对纯文字与含图任务明确分流。纯文字模型对202道含图题不能默认为可解，也不能静默漏算。
2. 实现答案解析、失败/拒答/超时分类和逐题日志。原模型响应保存，答案映射仅A/B/C/D；解析失败独立统计，不能挑选更有利的答案。记录提示词版本、模型配置、运行ID及数据摘要。
3. 实现汇总。总体准确率及年级/模块/暂定难度分层结果；测试集按300个完整母题—变式对计算两题同时正确率、一致性和答案变化。开发集无变式，不计算题对指标；对应功能先用独立构造的模拟数据调试，不使用测试题。报告样本量、缺失与不适用题，避免把未运行当错误或正确。
4. 先用本地固定模拟响应验证程序，覆盖四个答案、格式噪声、无效响应、失败日志和图片缺失。模拟结果只能验证程序，不作为模型表现。
5. 实际模型试运行只使用debug100，随后按固定配置使用其余开发集。模型、图像能力、调用接口和预算明确后才运行有成本的调用；当前未配置或启动。
6. 按原计划进入集中质量复核：公开题分层抽查、41道异常源解析与其他已知高风险题优先核查、变式正式复核、标签和语义近重复审查，修订记录与最终冻结。完整测试实验使用冻结版本，避免对测试答案调参。

简单的数据和日志核对继续使用Luna；数学推导、分组疑义和指标口径由主智能体处理。当前独立结构审计已完成，不等同于数学、许可或真实浏览器审查。
