# 暂定难度标注 v0.2

适用范围：公开题初版中difficulty=pending的1265题。七、八、九年级分别393、443、429题，输入快照保存在data/difficulty_work/input_public_questions_20261013.jsonl。已有235条标签本轮不自动覆盖。

| 标签 | 题面判断依据 |
|---|---|
| 基础 | 直接辨识概念或性质；代入标准公式；单一知识的常规计算或标准一步转换 |
| 中等 | 需要数步转换、建立模型、联系多个条件或知识点；常规综合推理 |
| 困难 | 需要实质分类讨论、非显然的条件组合、较复杂推理或综合应用；应记录具体困难所在 |
| pending | 题面无法可靠判断所需步骤、存在歧义或质量问题，保留原因 |

不因出现参数、长题干、竞赛来源、九年级或“综合”知识标签自动提高难度。步骤数量也不能单独决定难度，若只是重复机械计算，应结合所需概念和判断。目标600/600/300是覆盖设计，不是标注结果；不为凑比例修改标签。

标注阅读完整题干与四个选项，判断任务需求，允许参考来源已给出的解析；不要求本阶段逐题重新解答。每题附表保存id、difficulty、具体reason、model、annotated_at、review_method、rule_version与confidence。模型标签一律暂定，不等同于实测难度或数学复核；最终难度可结合后期人员复核再定稿。

题干、选项、源答案与稳定题号保持原样。发现可确认的质量问题另存候选清单，由主代理分诊；未经处理不把错误题标为困难。主代理检查覆盖与明显误标，重新合并后同步通用导出、本地页面及未知项清单。
