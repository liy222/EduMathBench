## 执行流程

1. 一次取得整包资料并归档，建立文件级来源登记；每题继承文件来源，保留原始题号和行号，不重复手工登记。
2. 本地脚本批量提取题干、选项、来源答案和已有知识标签；先过滤题型、非法答案、缺项、图依赖与明显残缺，不逐题重新解答。
3. 对整批精确去重；近重复只分组。原题、图形候选、异常、范围待定分开保存，不逐项打断大批量采集。
4. 按主要知识规则批量映射年级和五模块；Luna只处理脚本无法明确分类的成批记录，Sol只处理公式、来源或范围有争议的小量记录。源难度不得直接当本计划难度，先映射或pending。
5. 根据既定1500题覆盖格选择初版，输出实际缺口。竞赛题限定为范围合适的补充，避免为凑数量把全库变成竞赛题库。特别检查统计、纯文本几何和基础题覆盖。
6. 对缺口批量取得带答案的考试原卷/同步资料，按文件统一解析；集中复核按原计划后移。确认可直接退回的题及时退回，不阻塞其他批次。

这能快速完成候选材料取得；覆盖全部配额的耗时仍取决于筛选后的可用分布，不能仅凭下载总题数承诺当天完成1500题初版。
