当前并发上限4（含主代理），采用主代理＋3名采集者。角色超过槽位时串行轮换，不同时创建全部岗位。首批Sol验证后，常规批次默认Luna；含缺失图形、公式损坏、来源答案不明确等问题的任务回交Sol，不能自动猜测。

本轮以首批小样本跑通来源→提取→结构检查→去重→配额汇总，数量由实际可访问来源决定；这是数据收集启动批次，不宣称1500题里程碑已完成。

以上启动说明对应2026-10-09的小批次。之后按用户要求改为整包处理与缺口补题；截至2026-10-13，批量标签、统计/几何/概率/分式方程/函数的常规提取及来源对应核对均已实际交由gpt-6-luna / high轮换执行，主代理负责分类争议、已知源错误、配额合并及最终导出。最后一轮使用finish_fraction_collection补缺、final_provenance_audit做来源文本对应审计；并发仍不超过含主代理4槽。数学集中复核尚未启动，不能将此来源核对当作全量独立解答。

首批Sol代理完成后，已实际轮换启动两名`gpt-6-luna / high`：`luna_batch_extract`负责已验证七年级来源的新增采集，`luna_difficulty_tags`负责现有题的暂定难度登记。标注以独立附表保存，原始来源批次不覆盖；只在初版合并时附加暂定标签与模型记录。

选型依据：[OpenAI官方子智能体文档](https://learn.chatgpt.com/docs/agent-configuration/subagents)建议Luna用于明确、可重复任务，Sol用于复杂多步骤任务。具体岗位配置是本项目的工作安排，未测量成本或速度差异。
